# [WIP] Toby

Work in progress, version **0.0.7**. Requires Factorio **2.1.20 or later**. Production planning works without AI or a Facmandu connection. AI chat requires a Facmandu-managed server. Installing the mod alone does not connect an AI model.

Click the **Toby icon** above the game view or use its game shortcut, or press **Ctrl+Shift+T**, to open the side panel. **New chat** starts a separate conversation without stopping an existing run. **Chat** shows recent messages, **Activity** shows completed tool outcomes, errors and current work. **Design** shows the latest validated working draft or final blueprint, with warnings and construction costs. Inspections are labeled separately. Tab scroll positions survive progress updates. Status, elapsed time and tool results update while Toby works. Switch conversations while a run continues, or use **Steer** to add instructions. Press **Enter** to send or steer. Closing the panel keeps your typed draft. Shortcuts are configurable in Factorio’s Controls settings.

**Inspect blueprint** uses Factorio's blueprint editor. Press **Ctrl+Shift+Enter** from the message input, or **Ctrl+Shift+B** from the game view, to open it with the keyboard. **Take blueprint** puts the design in your cursor and closes the panel so you can place it. Both preserve your held item through Factorio's clear-cursor operation and refuse when the item cannot be returned to your inventory. Neither supplies construction materials.

Install this mod on the server **and every client**. Enable the in-game assistant in Facmandu's server settings. The mod contains no model credentials and has no network client. Player GUI events are emitted into the server log; Facmandu checks the connected player and conversation ownership before dispatch. Responses arrive over the existing private RCON connection. Existing force and action permissions apply.

Ambient mode is optional in server settings and requires a connected NeuralWatt account with Clef access. It sends ordinary player chat and recent assistant context to Clef for routing. Bare `@`, `@toby`, and `@assistant` remain direct requests.

**Drone** (or **Ctrl+Shift+D** from the game view) controls Toby’s own automatic companion, independently of Entourage. It appears when you join with a character and follows between surfaces. No crafting, equipment, robots, fuel or charging is needed. Construction follows Entourage’s reserve/revive/refund pattern and consumes actual items from Toby’s cargo, your inventory or nearby same-force provider/storage chests. Missing materials leave ghosts untouched. **Inventory** opens cargo; the legacy grid remains only to preserve equipment from earlier development builds. **Follow me** and **Stay here** control movement; the assistant can send Toby to an explored destination within 256 tiles. It pauses when you disconnect without losing cargo. Encoded vehicle items are left intact until their entity-data placement is supported; no research or building materials are granted.

**Planning** opens Toby’s built-in Factory Planner fork; **Agent** returns to the conversation workspace. Keep product, belt, machine-count and nested-floor planning. **Input supply** sets exact consumption or maximum available rates and can maximize a selected output. Blank supply rates remain unrestricted. Calculated usage and unused supply appear beside each input. These controls use the native simplex solver and persist with the plan. The original MIT, translation and bundled graphics notices are retained under `planner/`.

Factory Planner and Helmod plans can be read through their native APIs. Temporary native simplex calculations require the Factory Planner calculation API; the tool catalog reports whether the installed build exposes it. Calculations preserve your plans, preferences and selection. Helmod’s native recipe calculator needs no adapter. Task List requires its separate adapter for shared force tasks. Automated sandbox trials are still pending.

Referenced items, fluids, recipes and entities have native icon buttons below messages. Click or **Alt-click** them to open Factoriopedia; technology buttons open Research. Materials use the same controls.

Toby has an original industrial drone body with seven animated screen states. Floating speech reports public work progress near your companion, at most once every ten seconds; it never exposes private model reasoning. **Drone** shows the current activity, location and number of ghosts built.

Plans are shared with your Factorio force; selections and preferences remain personal. Use **Share** in the planner to copy a `toby://plan/<force>/<id>` reference or attach it to Toby’s draft. Toby can create saved plans and read these references when its host tools are connected. Plan edits carry a revision so an old proposal cannot overwrite newer work.

The agent workspace uses a chat sidebar with actual task status and a larger conversation pane. **Books** keeps each conversation’s latest design in the save, shared with your force. **Take Toby book** creates an organized book; **Update held book** appends current designs while preserving existing entries and edits. Drag the resulting book into Factorio’s **Game blueprints** shelf yourself: the mod API cannot create library records.
