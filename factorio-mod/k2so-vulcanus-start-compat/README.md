# [WIP] K2SO Vulcanus Start Compatibility

For Factorio 2.1, Any Planet Start 1.2.5 and Krastorio 2 Spaced Out 2.0.17.

On a Vulcanus start, Any Planet Start requires electronics before automation and red science. Krastorio adds automation and red science as prerequisites of electronics, creating a cycle.

On Vulcanus, this mod fixes three blocked research paths:

- Electronics: smelt five copper plates when K2 introduces the reversed prerequisite.
- Crusher: smelt 50 stone bricks instead of crafting 50 raw stone. The automation-core prerequisite is preserved.
- Rare metal processing: research it with science packs, at the same cost as rare metal mining. K2 unlocks it by mining rare metal ore, which only spawns on Nauvis, and it gates advanced chemistry and the hydrogen chloride needed to make rare metals from lava. The rare metal mining prerequisite is preserved.

It gives no items and grants no research. Other planet starts are unchanged.
